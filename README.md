# MTalks — Life & Marriage Coaching Platform

**Client:** Coach Madinah Sanni · Abuja, Nigeria  
**Domain:** [www.muhsinahacademy.com](https://www.muhsinahacademy.com)  
**Stack:** Vue 3 · Express.js · MySQL · Paystack · Three.js · JWT

> Helping Muslim Sisters and Couples Build Stronger, Healthier, and Lasting Relationships.

## Quick Start

```bash
# Backend
cd server && npm install && npm run dev

# Frontend
cd client && npm install && npm run dev
```

See [BLUEPRINT.md](./BLUEPRINT.md) for the full engineering specification.
